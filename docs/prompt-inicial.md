Esta es una aplicación de apoyo a traductores profesionales. El primer módulo debe permitir cargar archivos PDF con instrucciones y guías de estilo de traducción para iniciar el flujo desde el documento entregado por el cliente. En esta primera historia, la app valida el archivo, muestra estados y deja el PDF listo para el siguiente paso.
Para esto genera en [specs](docs/specs) los archivos de specs correspondientes, un plan de implementación en [docs](docs) y espera mi validación. Aún no codifiques nada.
